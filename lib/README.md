# ADK-bibliotek (checkas inte in)

Kopiera hit från ett befintligt ADK.NET-projekt (t.ex. `_lib` i Mobigo.Extension.SitterIT.SpirisHistory):

- `AvSynkLib.dll`
- `AdkNet4Wrapper.dll`

Filerna är licensierade (Visma/Avazon) och ska inte ligga i git – repot är publikt.
Vid körning måste Visma Administration (ADK) vara installerat på servern.
